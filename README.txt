These databases will only work with Cascade Server 6.4.0 or newer. See ./more/archive for older versions of the default database.

The 'cascade_db_publishing_schema' database is the MySQL schema required for database publishing. For more information, see: http://www.hannonhill.com/kb/Database-Publishing/

The schema name for the Oracle database dump is CASCADE_DEFAULT.

These databases work with Cascade CMS versions up to 2025.2.2. Any future versions will require an intermediate step consisting of first starting Cascade 2025.2.2 against the imported database, ensuring the login screen loads without errors, and then upgrading to any future version.
